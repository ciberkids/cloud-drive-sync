Privacy Policy

Last updated: April 8, 2026

Overview

Cloud Drive Sync is a free, open-source desktop application that synchronizes files between your computer and cloud storage providers. Your privacy is fundamental to how the application is designed.

Data Collection

Cloud Drive Sync does not collect, transmit, or store any user data on external servers. The application runs entirely on your device. There is no analytics, telemetry, crash reporting, or tracking of any kind.

Cloud Provider Access

Cloud Drive Sync accesses your cloud storage accounts (Google Drive, Dropbox, OneDrive, Nextcloud, Box) solely to perform the file synchronization you configure. Specifically:

  • Google Drive: The app requests the drive scope to read, create, modify, and delete files in your Google Drive, as needed for bidirectional sync. It also reads your email address to identify your account.
  • Other providers: Similar file read/write access is requested for each provider you connect.

The app communicates directly with each provider's API over HTTPS. No data passes through any intermediary server.

Data Storage

All application data is stored locally on your device:

  • OAuth tokens: Stored encrypted on disk using Fernet symmetric encryption with a machine-specific key. Tokens are per-account and can be revoked at any time.
  • Sync state database: An SQLite database tracking which files have been synced. Contains file paths, checksums, and timestamps — no file contents.
  • Configuration: A TOML file with your sync folder mappings and preferences.

Data Sharing

Cloud Drive Sync does not share your data with any third party. The application has no server component, no user accounts, and no network communication beyond the direct API calls to your configured cloud storage providers.

Open Source

The complete source code is publicly available at github.com/ciberkids/cloud-drive-sync under the MIT license. You can inspect exactly what the application does with your data.

Token Revocation

You can revoke Cloud Drive Sync's access to your cloud accounts at any time:

  • Google Drive: Google Account Permissions
  • Dropbox: Dropbox Connected Apps
  • OneDrive: Microsoft App Access

You can also remove accounts from within the application (UI or CLI), which deletes the stored tokens from your device.

Children's Privacy

Cloud Drive Sync is not directed at children under 13 and does not knowingly collect information from children.

Changes to This Policy

Any changes to this privacy policy will be published in the application's GitHub repository and reflected on this page.

Contact

For privacy questions or concerns, please open an issue on GitHub.
