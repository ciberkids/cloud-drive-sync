What it does

Cloud Drive Sync keeps your local folders in sync with cloud storage — bidirectionally, in real time. Changes on your computer are uploaded; changes in the cloud are downloaded. Conflicts are detected and resolved automatically or with your input.

How it works

The app runs as two components: a background daemon that handles all sync operations, and a desktop UI (or web UI for servers) for management. The daemon communicates directly with cloud provider APIs over HTTPS. All data stays on your machine and in your cloud storage — no third-party servers involved.

Open Source

Cloud Drive Sync is free and open-source under the MIT license. The full source code is available on GitHub.
